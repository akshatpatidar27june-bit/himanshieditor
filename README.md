# Himanshi — Visual Editor & Storyteller

A premium, responsive portfolio website for Himanshi, built with Vite and custom CSS.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Site sections

- Cinematic hero with layered visual composition
- About / creative philosophy
- Editing, color, motion and sound expertise
- Creative manifesto
- Four-step process
- Email and Instagram contact links

The website intentionally has no portfolio video showcase section. Replace the editorial imagery with licensed project stills as the portfolio evolves.
